# 2026-05-11 SAMS UI Review Notes

이 문서는 5월 11일 회의와 화면 캡처 기반 수정사항을 Codex가 읽기 쉬운 형태로 정리한 입력 문서입니다.

## 1. Explorer

### 아이콘 인터랙션

- 아이콘 hover 시 파일명 또는 사람이 읽는 표시명 표시
- 아이콘 click 시 Explorer 리스트에서 해당 항목 highlight

### 에셋 상세 패널

- 현재 선택된 에셋의 할당 프로젝트 정보 표시
- Draft 상태와 누락 필수 메타데이터 표시

### Draft 파일 모아보기

현재 문제:

- Explorer 리스트에서 데이터를 선택해야 사이드 상세 패널에서 Draft 상태 확인 가능
- Project에서만 Draft를 모아볼 수 있어 프로젝트에 할당되지 않은 Draft 파일을 찾기 어려움

개선 제안:

- 리스트 썸네일 왼쪽에 노란 점 또는 경고 배지 표시
- Draft 파일을 하단 또는 별도 필터로 모아보기
- Upload 완료 화면에도 Draft 후속 처리 버튼 제공

### 프로젝트 필터 개선

- 프로젝트가 많아지면 리스트가 길어짐
- 상태/site/project 검색 또는 그룹화 필요

### 검색 기능 확인

- 현재 UI만 있는지, 실제 검색 API/필터와 연결되어 있는지 repo audit 필요

## 2. Item Detail

### 메타데이터 입력폼

드롭다운 권장 항목:

- `project:name`
- `data_category`
- `sams:status` 또는 `properties.status`

placeholder 개선:

- `입력하세요` 대신 형식 예시를 표시
- 예: `성수동`, `YYYY-MM-DD`, `EPSG:5186`

커스텀 메타데이터:

- 데이터 유형별 확장 필드 유지
- 사람이 부여하는 파일 이름 `title` 또는 `display_name` 추가
- 미입력 시 기존 파일명 사용
- 키워드 필드 추가

## 3. Project

### 프로젝트 미할당 Draft 처리

문제:

- Collection 미지정 업로드 후 프로젝트로 이동하면 임시 빈 프로젝트가 제거되지 않고 남음
- `upload-...` 이름의 빈 프로젝트가 다수 생김

개선 방향:

- 임시 프로젝트 대신 시스템 예약 Collection/Inbox 사용
- 예: `Unassigned`, `Inbox`, `Master Null Project`
- 프로젝트로 이동 완료 후 빈 임시 프로젝트 자동 제거

### 프로젝트 편집 추가

편집 가능 항목:

- 프로젝트명/title
- 개요/description
- 기간
- 발주처
- PM 정보
- 기본 좌표계
- 예상 산출물
- 상태

프로젝트 ID는 고유번호이므로 수정 불가.

### Project → 에셋 연결

- 프로젝트 관리 페이지에서 에셋을 직접 검색/선택하여 담는 기능 필요
- 한 에셋이 여러 프로젝트에 사용될 수 있도록 중복 할당 허용
- 물리 파일 복사보다는 membership/association 추가 방식 권장

### 위치 정보 표시

- bbox 숫자만 표시하는 방식은 사용자가 이해하기 어려움
- 기본 화면에는 지도 footprint, 중심점, 주소/사이트명, 자동/수동 추출 상태 표시
- bbox 원시값은 고급 정보로 숨김

### 현황 페이지 지도뷰 통합

- Project 현황 탭에 해당 프로젝트 에셋만 필터링된 지도 추가 검토
- 전체 아이콘이 화면에 들어오도록 자동 줌
- 공간 탭을 현황 탭에 통합할지 검토
- 단, Explorer에서 프로젝트 필터링이 가능하므로 중복성 검토 필요

### 연관관계

- 현재는 다른 프로젝트에 할당된 에셋끼리는 연결 불가한 것으로 보임
- 프로젝트 내 관계가 아니라 에셋 자체 간 관계로 설계 가능한지 검토

## 4. Upload

### Collection 지정 후 업로드

- 기존 Collection에 포함된 파일들의 위치를 기준으로 지도 중심점 자동 설정
- 하단 주소 검색창 필요
- description 수정 시 파일명도 수정되는 현상 확인 필요

### 완료 후 버튼

추가 버튼:

- `Item 상세 페이지로 이동`
- `수동 입력 필요 항목 편집하기`
- `Explorer에서 Draft 보기`
- `Project로 이동`

- 시계열 데이터 입력 보조
